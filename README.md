# BrainTumorApp
🧠 مشروع: نظام الكشف عن أورام الدماغ باستخدام التعلم العميق
(Brain Tumor Classification Web Application using Deep Learning)
🎯 1. نبذة عن المشروع (Project Objective)
تم بناء نظام ذكاء اصطناعي متكامل (End-to-End Machine Learning Project) يهدف إلى مساعدة الأطباء وأخصائيي الأشعة في التحليل السريع لصور أشعة الرنين المغناطيسي (MRI). يقوم النظام باكتشاف وجود أورام الدماغ، وتصنيفها بدقة إلى 4 فئات رئيسية:
ورم دبقي (Glioma Tumor)
ورم سحائي (Meningioma Tumor)
ورم الغدة النخامية (Pituitary Tumor)
دماغ سليم / لا يوجد ورم (No Tumor)
🛠️ 2. التقنيات المستخدمة (Technology Stack)
لغة البرمجة: Python.
بناء وتدريب النماذج: TensorFlow & Keras.
معالجة الصور: PIL & NumPy.
التقييم والرسم البياني: Matplotlib, Seaborn, Scikit-learn.
واجهة الويب (Web App): Streamlit.
🚀 3. خطوات التنفيذ بالتفصيل (Methodology)
تم تنفيذ المشروع بناءً على دورة حياة الذكاء الاصطناعي القياسية، ومقسماً إلى المراحل التالية:
أ. جمع البيانات (Data Acquisition)
تم الحصول على مجموعة البيانات من منصة Kaggle. تحتوي البيانات على آلاف من صور أشعة الرنين المغناطيسي للدماغ (MRI)، مقسمة مسبقاً إلى مجلدات تدريب (Training) واختبار (Testing).
ب. معالجة البيانات وتحسينها (Pre-Processing & Augmentation)
نظراً لأن الصور الطبية حساسة، تم التعامل معها بعناية:
Pre-Processing: تم توحيد حجم جميع الصور إلى (224x224 بيكسل)، وتم عمل Normalization (تحويل قيم البيكسل لتصبح بين 0 و 1) لتسريع عملية التدريب.
Data Augmentation: لتجنب مشكلة حفظ النموذج للبيانات (Overfitting)، قمنا بتطبيق تقنيات مثل (الدوران البسيط، الإزاحة الأفقية والرأسية، والتكبير) على بيانات التدريب فقط لزيادة تنوع الصور وجعل النموذج أكثر قدرة على التعميم.
ج. بناء النماذج (Modeling)
تم بناء وتجربة نموذجين مختلفين للمقارنة بينهما:
نموذج مبني من الصفر (CNN From Scratch): تم تصميم معمارية شبكة عصبية التفافية خاصة بنا. حقق النموذج دقة تدريب عالية تتجاوز 80%، لكن دقة الاختبار (Validation) توقفت عند حوالي 54%. استنتجنا من ذلك أن النموذج يعاني من Overfitting لأن البيانات الطبية معقدة وتحتاج إلى استخراج ملامح (Features) أعمق.
استخدام نموذج جاهز (Pretrained Model - Transfer Learning): لحل المشكلة السابقة، قمنا باستخدام معمارية VGG16 العالمية. قمنا بتجميد الطبقات الأساسية (Base Layers) واستخدمنا خبرتها في قراءة الصور، ثم أضفنا طبقاتنا الخاصة (Dense Layers) لتصنيف الأورام. أدى هذا إلى قفزة ممتازة في الأداء حيث ارتفعت الدقة لتصل إلى حوالي 70% في عدد دورات (Epochs) قليل جداً.
د. التقييم والرسومات البيانية (Evaluation & Visualization)
تم تقييم النموذج النهائي (VGG16) باستخدام مقاييس علمية دقيقة:
تم رسم منحنيات الـ Accuracy & Loss عبر الـ Epochs لمراقبة أداء النموذج وتأكيد عدم وجود Overfitting شديد.
تم استخراج Classification Report لقياس الـ (Precision, Recall, F1-Score).
تم رسم Confusion Matrix (مصفوفة الارتباك) لمعرفة أين يخطئ النموذج بالتحديد بين فئات الأورام الأربعة.
هـ. التطبيق العملي (Web Application)
لم نكتفِ بكتابة الكود فقط، بل قمنا بتحويل النموذج الذكي إلى تطبيق ويب تفاعلي باستخدام مكتبة Streamlit. يسمح التطبيق للمستخدم (الطبيب) برفع صورة أشعة MRI من جهازه، ليقوم النظام في ثوانٍ معدودة بمعالجة الصورة، إدخالها للنموذج، وعرض نوع الورم المكتشف مع "نسبة ثقة (Confidence Score)" خاصة بالذكاء الاصطناعي.
